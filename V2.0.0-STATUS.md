## Getting Started with Development

1. The plugin system is ready to use - see `packages/magic-helix-core/src/plugin-system.ts`
2. Example plugins are in `packages/magic-helix-core/src/plugins/`
3. Documentation is in `PLUGIN-SYSTEM.md`
4. To add a new plugin:
   - Create a new file in `packages/magic-helix-core/src/plugins/`
   - Implement the `DetectionPlugin` interface
   - Export it from `packages/magic-helix-core/src/plugins/index.ts`
   - Add tests in `*.test.ts` file
   - Create corresponding template files
   - Update documentation
